# Practicas - Testing y Calidad de Software

## Descripcion
Este repositorio contiene las practicas, ejercicios y actividades desarrolladas durante la materia de Testing y Calidad de Software.

Su finalidad es mantener organizados los trabajos realizados en clase y registrar los avances mediante Git y GitHub.

## Objetivos
- Organizar las practicas desarrolladas.
- Guardar ejercicios y documentos.
- Registrar evidencias de las actividades.
- Aplicar conocimientos de testing.
- Utilizar Git y GitHub para controlar versiones.

## Contenido
- Fundamentos de testing.
- Pruebas funcionales.
- Diseno de casos de prueba.
- Retesting y Regression Testing.
- Git y GitHub.
- Issues y Project Boards.
- Automatizacion de pruebas.

## Estructura
- practicas/: trabajos practicos.
- ejercicios/: ejercicios de clase.
- evidencias/: capturas y resultados.
- informes/: documentos de las actividades.

En desarrollo durante el semestre.
